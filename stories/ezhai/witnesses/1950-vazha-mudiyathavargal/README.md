## Highest-value edition findings

Notable source-supported differences include:

- heading physically damaged in 1950; opening-body identity remains secure;
- `சும்மாயிருப்பதில்லை` ↔ canonical `சும்மா இருப்பதில்லை`;
- 1950 uses `தொடர்ச்சி கெடும்படி` where 1977 has `தொடர்ச்சி கெடுக்கும்படி`;
- `காசைத் தூசியாக` ↔ canonical `காசைத் தூசாக`;
- the 1950 nose-stud dream shifts into direct-speech style around **`முக்குத்தி வாங்கி வருகிறேன்`**, whereas 1977 narrates `முக்குத்தி வாங்கி வருகிறான் அத்தான்`;
- 1950 `கனவு பங்கம் பாடுகிறது` ↔ canonical `கனவு மங்கலம் பாடுகிறது`;
