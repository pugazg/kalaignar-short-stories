## Highest-value edition findings

The 1950 witness contains genuine wording, morphology, spelling, punctuation, spacing and layout differences. Among the most useful:

- story heading: `ஒரிஜினலில் உள்ளபடி!` ↔ canonical heading without the terminal exclamation;
- after `உம் போ.`, 1950 repeats `ஒரிஜினலில் உள்ளபடி போடு.`; this sentence is absent from the 1977 canonical;
- 1950 describes the opening exchange as `நடந்த உரையாடல் மேல் காண்பது.` while the canonical has the shorter `நடந்த உரையாடல்!`;
- `திரெளபதி அம்மன் கோயில்` ↔ canonical `திரெளபதி அம்மன் கோவில்`;
- `வெளிக் கிளம்பிற்று` ↔ canonical `வெளிக் கிளம்பின`;
- 1950 adds `தித்திக்கும்` before `தேன் சுவைக் கவிதைகளை`;
- `அலைகழியும் மலர்க் கூட்டம்` ↔ canonical source-close `அலக் கழியும் மலர்க் கூட்டம்`;
