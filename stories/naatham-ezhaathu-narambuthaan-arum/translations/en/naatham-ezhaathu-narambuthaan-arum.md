# No Music Will Rise — Only the String Will Snap

<!-- source scan 14; printed page 13 -->

Buddha met a young man. Buddha said to that young man:— “O young man! If the veena's string is tightened too much, or loosened too much, good music cannot be heard.”

“If sweet resonance — joyful resonance — beautiful music is to arise from the veena's string, the string must be tightened only to the degree required. ‘I

will tighten it only this way,’ if it is tightened like that, instead of music arising, the string itself will snap.
