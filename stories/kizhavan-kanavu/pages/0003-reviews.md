# அச்சு உரை

## “குடியரசு”

ஈரோடு,
12—5—45.

கிழவன் கண்ட கனவு எவ்வாறு நினைவாயிற்று என்பதை ஆசிரியர் இச்சிறு நூலில் அழகாகத் தீட்டியிருக்கிறார். பணம் படைத்தவர், எதை வேண்டுமானாலும் செய்யலாம் என்பதையும் இதில் காணலாம். உண்மையான காதல் எது? என்பதையும் தெரிந்து கொள்ளலாம். விடுதலைக்கொடி தோன்றுவதாக விபுலானந்தரும் மல்லிகாவும் காணும் கனவை நினைவாக [blocked-by-source: பெரிய library stamp இங்கு அச்சுச் சொற்களை முழுமையாக மறைக்கிறது] முக்கியத்தை வலியுறுத்தி [blocked-by-source: அதே library stamp குறும் அச்சுப் பகுதியை மறைக்கிறது] இச்சிறு நூலில் ஆசிரியர். இத்தகைய நூல்களை ஆதரிக்க வேண்டியது தமிழ் மக்களின் கடமையாகும்.

## “தொழிலாளர்”

புதுவை,

கிழவன் கனவைத் தீட்டிய தோழர் மு. கருணாநிதி நல்ல இளம் எழுத்தாளர். இந்தச் சிறு நூலில் எதிர்காலத் திராவிடம் அழகாக சித்தரிக்கப்பட்டிருக்கிறது. திராவிட மக்களின் ஆதரவு கிடைக்குமென்று நம்புகிறோம்.

## அச்சு அல்லாத / physical-copy marks

- மேல் `“குடியரசு”` மதிப்புரையின் நடு/கீழ்பகுதியில் பெரிய வட்ட/oval library stamp அச்சு உரையின் மீது பதிந்து சில சொற்களை முழுமையாக மறைக்கிறது.
- `“தொழிலாளர்”` heading அருகிலும் தனி stamp/ink mark உள்ளது; heading-ன் நடுப்பகுதி மீது முத்திரை படிந்திருந்தாலும் கீழுள்ள மதிப்புரை வாசிக்கத் தெளிவாக உள்ளது.
- reverse-side bleed-through மற்றும் uneven contrast காணப்படுகிறது.
