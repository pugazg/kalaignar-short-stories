## Source-sensitive canonical forms checked

- 1969 independently reads **`கூண்டுக் கிளி ஆக்குவேனென்றான்`** — supports the current 1977 canonical repair and rejects the earlier provisional `ஆகுவேனென்றான்`.
- 1969 reads **`அருமையான யோசனைதான்!`** as one word, whereas the exact 1977 scan supports canonical **`அருமையான யோசனை தான்!`**. This is an edition-level spacing difference; the canonical stays unchanged.
- 1969 retains unusual **`கந்தனு?`**, independently supporting that current 1977 source-close reading.
- The final scene is narratively equivalent, but 1969 has **`என் வாழ்வைத் துண்டித்த சண்டாளா`** where the verified 1977 canonical has **`வாழ்க்கைத் துண்டித்த சண்டாளா`**. This is recorded as an edition wording variant, not a canonical correction.
