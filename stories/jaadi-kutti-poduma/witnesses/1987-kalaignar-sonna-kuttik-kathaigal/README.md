The distinctive narrative sequence is the same as canonical `ஜாடி குட்டி போடுமா?`:

1. a jar is borrowed;
2. the borrower returns the jar with smaller jars and claims the jar produced offspring;
3. a more valuable jar is later borrowed;
4. the borrower claims that jar died in childbirth;
5. the anecdote exposes the inconsistency of accepting an impossible gain and rejecting an impossible loss.
