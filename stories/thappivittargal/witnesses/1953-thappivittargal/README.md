## High-value edition findings

Representative source-supported differences include:

- 1953 `போடக்கூடாது` ↔ 1977 source-verified `போட்டுக்கூடாது`;
- 1953 `மூவாயிரம் தொழிலாளர் வேலை செய்தனர்` ↔ 1977 `மூவாயிரம் தொழிலாளர்கள் வேலை செய்தனர்`;
- 1953 uses a centered **three-open-circle divider** before the Leela Mill narrative block, whereas the 1977 canonical represents that transition through paragraph structure / enlarged initial rather than this divider;
- 1953 has several spacing / morphology differences around compounds and sandhi, including forms such as `தன் ஆசை அனைத்தையும்` where 1977 has `ஆசையனைத்தையும்`;
- the closing page preserves the same final line `சமுதாயக் கொடுமையிலிருந்து இருவருமே தப்பிவிட்டார்கள்.` but ends with a simple centered short rule rather than the 1977 ornamental flourish.

The 1953 witness also preserves many of the same source-close lexical choices found later, including `எச்சிற் பண்டம்`, `கூர்க்கா`, `குபு குபு`, and the basic escape / station sequence.
